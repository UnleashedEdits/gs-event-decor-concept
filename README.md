# GS Event Decor — local concept

Separate adaptation of `../event-studio-template/`; the reusable Forme project is unchanged.
Buildless HTML, CSS and JavaScript. No installed dependencies, backend, tracking or submission service.

## Preview

Run `npm run dev` in this folder, then open http://127.0.0.1:5182/.
Run `npm run check` for the original template's JavaScript syntax checks.
Edit `business.js` for business content, colours, contacts, approved images, services, projects, FAQs and publication decisions.
